\# Unity Slot Machine Game



Submission for the Underpin Technology - Unity Developer Intern Assignment.



\## 🎮 Project Overview

This is a fully playable 3-reel slot machine game built in Unity. It features smooth vertical reel animations, strict winning logic, a Wild symbol bonus feature, and a weighted RNG system. 



The entire scene can be automatically generated using a custom Unity Editor tool.



\## 🚀 How to Run \& Test

1\. Clone this repository and open it in Unity (Unity 6 or newer recommended).

2\. In the top Unity menu bar, click on \*\*`Underpin Slot Game`\*\* -> \*\*`Build Complete Slot Machine`\*\*.

3\. A dialog box will appear confirming the scene is created. Click \*\*"Let's Play"\*\*.

4\. Press the \*\*Play\*\* button at the top of the Unity Editor.

5\. Use the \*\*`SPIN`\*\* button to play. Adjust your bet using the \*\*`- BET`\*\* and \*\*`+ BET`\*\* buttons.

6\. Win by matching 3 identical symbols, or 2 identical symbols + 1 Wild!



\## ✨ Key Features

\- \*\*Smooth Reel Animations:\*\* Uses `RectMask2D` and a vertical scrolling strip with an `AnimationCurve` for natural deceleration.

\- \*\*Strict Win Logic:\*\* Only awards a payout for 3-of-a-kind or 2-of-a-kind + Wild.

\- \*\*Bonus Feature:\*\* A Wild symbol that substitutes for any other symbol.

\- \*\*Weighted RNG:\*\* Ensures a balanced gameplay experience.

\- \*\*Auto-Setup:\*\* Custom Editor menu item to generate the scene, UI, and EventSystem flawlessly.
